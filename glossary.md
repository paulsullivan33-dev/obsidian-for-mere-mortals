# Glossary

**Attachment.** Any file in a vault
that is not a Markdown note —
pictures, PDFs, recordings. Displayed
in a note by an embed, stored on
disk like anything else (chapter 10).

**Backlink.** A link in the other
direction: for the note you are
reading, the list of notes that link
*to* it (chapter 6).

**Base.** A saved table-style view
over the vault's files, filtered and
sorted by properties; a core feature
in current versions, kept as a
`.base` file of readable YAML
(chapter 14).

**Block link.** A wikilink aimed at
one marked paragraph inside a note:
`[[Note#^id]]` (chapter 5).

**Bookmarks.** Notes, searches and
other views you have marked for
keeping close; a core plugin, stored
in `.obsidian` (chapter 8).

**Canvas.** A core plugin providing
an infinite whiteboard; its boards
are `.canvas` files in JSON, an open
format (chapter 12).

**Command palette.** The searchable
list of everything the app and its
plugins can do, summoned by keyboard
(chapter 12).

**Community plugin.** A feature
written by someone other than the
maker, installed from inside the app
once restricted mode is off
(chapter 13).

**Core plugin.** One of the thirty
features that ship with the app,
switched on or off per vault in
`.obsidian/core-plugins.json`
(chapter 12).

**Daily note.** The note for a day,
kept by the daily-notes core plugin
in a named folder under a date name
(chapter 9).

**Dataview.** The best-known
community plugin: queries over
properties and tags that render as
live tables and lists (chapter 14).

**Embed.** A link with an exclamation
mark — `![[file]]` — that shows the
file's contents inside the note
rather than pointing onward
(chapter 10).

**Front matter.** The YAML block
between two `---` lines at the very
top of a note; the file form of
properties (chapter 7).

**Graph.** The map of notes and
links: global for the vault, local
around one note (chapter 6).

**Markdown.** The plain-text format
of the notes: text plus a light
dusting of marks for headings,
bold, lists and links
(chapter 4).

**Markdown link.** A link by path:
`[text](Folder/Note.md)` — universal
across Markdown tools, broken by
moves and renames alike
(chapter 5).

**Note.** One Markdown file in the
vault; the unit of everything.

**Orphan.** A note with no links in
or out, visible as an island in the
graph (chapter 6).

**Outgoing links.** The forward list:
everything the note you are reading
links to, gathered in one panel
(chapter 6).

**Plugin.** See core plugin and
community plugin; the word alone
usually means the community kind.

**Properties.** Name-and-value facts
about a note, written as YAML front
matter and shown by the app as a
form (chapter 7).

**Publish.** The maker's paid service
for putting selected notes on the
web as a site (chapter 14).

**Quick switcher.** The jump-to-a-note
box, by name, with fuzzy matching
(chapter 8).

**Restricted mode.** The default
state in which community plugins
cannot run; switching it off is the
gate of chapter 13. (Older versions:
safe mode.)

**Sync.** The maker's paid,
end-to-end encrypted service for
keeping a vault in step between
devices (chapter 11). Lowercase, a
sync is any copying that keeps two
folders alike.

**Sync conflict.** The state after
the same note was edited in two
places before they met; each method
of chapter 11 surfaces it
differently, none silently.

**Tag.** A label typed as `#word` in
a note's text or listed in its
`tags` property; nestable as
`#crop/summer` (chapter 7).

**Template.** A note whose text is
copied into new notes, with
`{{date}}`, `{{time}}` and `{{title}}`
filled in as it lands (chapter 9).

**Unlinked mention.** A place where
a note's name appears as plain text
without a link, found by the
backlinks panel (chapter 6).

**Unresolved link.** A wikilink
naming a note that does not exist
(yet); clicking it creates the note
(chapter 5).

**Vault.** The folder that is the
notebook: notes, attachments, and
one hidden settings folder
(chapter 2).

**Wikilink.** A link by name:
`[[Note]]`, with an optional display
alias after a `|`. Survives moves,
breaks on renames (chapter 5).

**`.obsidian`.** The hidden folder
inside a vault holding the app's
per-vault settings, all of it JSON
(chapter 2).
