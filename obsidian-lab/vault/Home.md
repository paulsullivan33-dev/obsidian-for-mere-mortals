# Home

This is the front door of the Bramble
Patch Notebook, one gardener's record
of a small vegetable garden. Everything
in this vault is a plain text file. If
you are reading this in a text editor
instead of Obsidian, nothing is missing
except the convenience.

Start anywhere:

- [[Tomatoes]] — this year's plants,
  and what they need
- [[Seed Inventory]] — what is in the
  seed tin, and what ran out
- [[Watering Schedule]] — who gets
  water, and when
- [[Garden Map]] — the beds, drawn and
  labelled
- The compost notes are kept as
  [a plain Markdown link](Compost.md),
  on purpose, so this vault contains
  both link styles side by side

Daily notes live in the Daily Notes
folder. New crop notes start from the
Crop Record template in the Templates
folder.
